## 이번 개편안, 딱 세 줄 요약

1. **1세대 1주택 '거주자'는 공제 확대** — 기본공제 12억 → 14억 (시가 약 20억까지 종부세 없음)
2. **'비거주' 1주택은 오히려 축소** — 공제 9억, 고령·장기 세액공제도 '거주'해야만 인정
3. **다주택자는 전방위 강화** — 공제 축소(9억 → 4억+α), 공정시장가액비율 최대 80%, 세율 인상

한 줄로 줄이면 이겁니다.

> **"살고 있으면 감세, 안 살면 증세."**

## 실제로 계산해보면 (계산기 결과 그대로)

### 사례 1. 공시 12억 · 1주택 거주 — "대부분은 변화 없음"

| | 보유세 |
|---|---|
| 현행 | 260만 원 |
| '28년~ | 260만 원 (변동 없음) |

과세 문턱(개편 후 공시 14억) 아래라 종부세 자체가 없습니다.
서울 아파트 평균 수준까지는 이번 개편과 무관합니다.

### 사례 2. 공시 15억 · 1주택 거주 (60세, 10년) — "오히려 줄어듭니다"

| | 보유세 |
|---|---|
| 현행 | 371만 원 |
| '28년~ | **354만 원 (−17만)** |

기본공제가 12억 → 14억으로 늘어난 효과입니다.
거주 중인 1주택자는 이번 개편의 수혜자입니다.

### 사례 3. 같은 15억인데 '비거주'라면 — "여기서 갈립니다"

| | 보유세 |
|---|---|
| 현행 | 371만 원 |
| '28년~ | **494만 원 (+123만)** |

똑같은 집인데 살지 않는다는 이유로,
사례 2와 비교하면 **연 140만 원 차이**가 납니다.

공제가 9억으로 줄고, '28년부터는 보유기간 공제가 사라지고
**거주기간 공제만** 인정되기 때문입니다.

전세 주고 다른 곳에 사는 1주택자라면, 이 부분을 꼭 확인하셔야 합니다.

### 사례 4. 공시 30억 · 70세 · 10년 거주 — "고가주택은 한도에 걸립니다"

| | 보유세 |
|---|---|
| 현행 | 916만 원 |
| '28년~ | **1,042만 원 (+126만)** |

연령공제 40% + 거주공제 40% = 세액공제율 80% 만점인데도 늘어납니다.
이번에 세액공제 **금액 한도**가 신설됐기 때문입니다. ('27년 800만 → '28년 600만)

공제율만 믿고 계시던 고령·장기보유 고가주택 보유자분들,
계산 결과가 예상과 다를 수 있습니다.

### 사례 5. 3주택 · 합산 30억 · 조정지역 — "약 1.8배"

| | 보유세 |
|---|---|
| 현행 | 1,974만 원 |
| '28년~ | **3,639만 원 (+1,665만)** |

다주택 기본공제 축소(9억 → 4억+거주주택 비중),
공정시장가액비율 80%, 세율 인상이 전부 겹친 결과입니다.

## 계산기 사용법 (30초)

1. **보유 형태 선택** — 1세대 1주택 / 다주택
2. **공시가격 입력** — 모르시면 계산기 안의 **국토교통부 알리미 바로가기**에서 조회
3. **연도별 카드 클릭** — 현행·'27·'28 각각의 재산세·종부세 상세 계산 과정까지 확인

## 꼭 알아두실 것

- 이번 개편안은 **국회 통과 전 '정부안'** 입니다. 확정 과정에서 세율·공제가 달라질 수 있고, 계산 결과는 참고용입니다.
- 재산세는 이번 개편 대상이 아니라 현행 그대로 계산됩니다.
- 공동명의, 일시적 2주택, 상속주택 특례 등은 사안별로 판단이 달라 계산기가 단순화해 보여줍니다.

- 부부 공동명의 유지 vs 단독 전환이 헷갈리는 분
